# Controle de Gastos Diários 💰

Projeto de estudos desenvolvido durante o 2º semestre da faculdade/cursos para praticar programação backend e banco de dados.

## 🛠️ O que estou usando:
* **Python**: Linguagem principal para criar a lógica do programa.
* **MySQL**: Banco de dados relacional para guardar as despesas com segurança.
* **VS Code**: Meu ambiente de desenvolvimento.

## 🎯 Objetivo:
Criar uma aplicação simples pelo terminal para cadastrar gastos, salvando tudo direto em um banco de dados local. Projeto em constante evolução conforme vou aprendendo novos conteúdos!
